# Олигарх — 3D-модели (low-poly)

90 моделей в формате GLB, созданы кодом, без нейросетей. Пересобрать: `cd generator && python3 build.py` (нужен только numpy).

- `models/industries/<отрасль>/<отрасль>_<ветка>_<уровень>.glb` — 8 отраслей × 3 ветки (rent / income / special) × 3 уровня.
- `models/tiles` — стройплощадка, Транссиб, порты, аэропорт, ГЭС, АЭС.
- `models/corners` — Старт, Казино, Экономический форум, Загул.
- `models/tokens` — 6 фишек; `models/props/dice.glb` — кубик.
- `models/manifest.json` — список моделей с русскими названиями, веткой, уровнем и числом треугольников.
- `preview/*.png` — листы предпросмотра.

Клетка — квадрат 2×2 единицы, ось Y вверх, основание высотой 0.08.
