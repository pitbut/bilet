# «Олигарх» — публикация в RuStore

## Что загружать

| Файл | Где взять | Зачем |
|---|---|---|
| `Oligarh-1.0.0.aab` (или `Oligarh-1.0.0.apk`) | собран в `prototype/android/app/build/outputs/…/release/` | сама игра; RuStore принимает и AAB, и APK |
| `assets/brand/icon-512.png` | в репозитории | иконка карточки, 512×512 |
| `store/phone/*.jpg` и `store/tablet/*.jpg` | в репозитории | скриншоты: телефон 1080×1920 (9:16), планшет 1920×1080 (16:9), минимум 3 в каждом |
| `site/` | выложить на свой сайт | `app-ads.txt` для Яндекса, политика конфиденциальности |

**Ключ подписи** (`oligarh-release.jks` + `keystore.properties`) хранится только у вас. Без него
нельзя выпустить обновление: RuStore примет новую версию, только если она подписана тем же ключом.
Сохраните оба файла в двух местах (облако + флешка). В репозиторий они не попадают.

## Карточка приложения

**Название:** Олигарх

**Краткое описание (до 80 символов):**
> Экономическая настольная игра: города России, стройки, биржа и банк

**Полное описание:**
> «Олигарх» — экономическая настольная игра про российские города. Покупайте предприятия от Сыктывкара до Москвы, собирайте отрасли — нефть, газ, металл, лес, автопром, туризм, финансы — и стройте империю.
>
> • Стройки идут на время. Пока ходят соперники, тапайте по своим стройкам — успели раньше срока, получите бонус к аренде.
> • У каждого здания своя ветка развития: аренда, постоянный доход или особый эффект.
> • Биржа: продавайте и покупайте акции компаний, получайте дивиденды, выкупайте чужие компании.
> • Банк: вклады под процент, кредиты под залог, складчина с другими игроками. Не вернули кредит — залог уйдёт с аукциона.
> • Звонки банка и биржи: сотрудник лично расскажет о выгодном предложении.
> • Роскошь со смыслом: особняк, яхта, спорткар и картины поднимают статус и доходы — и стоят на вашем участке в центре поля.
> • Казино вместо тюрьмы: рулетка, слоты, блэкджек и тотализатор на игровую валюту.
> • Играйте против ботов с характером, вдвоём на одном телефоне или с друзьями по Bluetooth — интернет не нужен.
> • Партия сохраняется сама — можно продолжить в любой момент.
>
> В игре нет покупок за реальные деньги. Казино — только на игровую валюту.

**Категория:** Игры → Настольные (запасной вариант — Стратегии)

**Возрастной рейтинг:** 16+ — в игре есть имитация азартных игр (казино на игровую валюту).
Если модерация попросит, поставьте 18+.

**Ключевые слова:** монополия, экономическая игра, настольная игра, бизнес, олигарх, биржа, акции, города России, стратегия, игра с друзьями, bluetooth

**Сайт разработчика:** адрес сайта, где лежит `app-ads.txt` (см. ниже) — обязательно тот же домен.

**Политика конфиденциальности:** `https://ваш-сайт/privacy.html`

**Реклама:** отметить «В приложении есть реклама».

**Платный контент:** нет.

## Разрешения — что ответить модерации

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | загрузка рекламы Яндекса |
| `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `BLUETOOTH_ADVERTISE` (Android 12+) | режим «Несколько телефонов»: найти стол друга и обмениваться ходами |
| `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION` (только Android 11 и ниже) | то же; на старых Android поиск Bluetooth-устройств требует разрешения на местоположение. Само местоположение игра не использует |
| `VIBRATE` | вибрация при входящем звонке банка или биржи |
| `AD_ID` | рекламный идентификатор для Рекламной сети Яндекса |

## Реклама Яндекса: что осталось сделать

1. В кабинете Рекламной сети Яндекса (partner.yandex.ru → Мобильные приложения) добавьте приложение
   `ru.oligarh.game` и создайте два блока:
   - **Rewarded** (с вознаграждением) — «Посмотреть рекламу: +100 млн»;
   - **Interstitial** (полноэкранный) — показывается после конца партии, не чаще раза в 3 минуты.
2. Номера блоков (`R-M-…`) впишите в `prototype/src/ui/ads.ts` вместо тестовых
   `demo-rewarded-yandex` и `demo-interstitial-yandex` и пересоберите (или пришлите номера — пересоберу).
3. Выложите `site/app-ads.txt` в **корень** сайта: `https://ваш-сайт/app-ads.txt`. Файл не менять.
4. Тот же сайт укажите в карточке RuStore. Яндекс проверит файл в течение 1–3 суток.

Пока стоят тестовые блоки, реклама показывается, но денег не приносит — для первой проверки это нормально.

## Сайт за 5 минут (GitHub Pages)

1. Создайте на GitHub репозиторий с именем **`<ваш-логин>.github.io`** (например, `pitbut.github.io`).
2. Загрузите в него всё содержимое папки `site/` (`index.html`, `privacy.html`, `app-ads.txt`, `icon.png`).
3. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
4. Через минуту сайт доступен: `https://pitbut.github.io/`, файл — `https://pitbut.github.io/app-ads.txt`.
5. В `privacy.html` замените `ВАШ_EMAIL` на почту для связи.

## Как собрать новую версию

```bash
cd prototype
# поднять versionCode и versionName в android/app/build.gradle и APP_VERSION в src/version.ts
npm run build && npx cap sync android
cd android && ./gradlew assembleRelease bundleRelease
```
`android/keystore.properties` должен указывать на ваш `oligarh-release.jks`.
