# Олигарх

Экономическая 3D-настолка для Android (RuStore) на российских городах: покупка бизнесов, стройки на время, ветки развития, аукционы, казино вместо тюрьмы, боты с характерами.

Дизайн-документ: https://claude.ai/code/artifact/88873c06-aa26-475f-91c6-11f9a5e28b26
Играбельный прототип: https://claude.ai/artifact/ANxrcsE8zRtdy6jUfgQCCd

## Структура

- `prototype/` — играбельный прототип (TypeScript + three.js + Vite).
  - `src/engine/` — правила без графики: поле, ход, стройки, аукцион, слияние, казино, карточки, рынок, банкротство, боты.
  - `src/ui/` — 3D-сцена и интерфейс.
  - `test/` — тесты правил (vitest).
  - `scripts/simulate.ts` — тысячи партий ботов для проверки баланса.
- `assets/` — low-poly 3D-модели (GLB) и их генератор на Python.

## Команды (в `prototype/`)

```bash
npm install
npm run dev        # локальный запуск в браузере
npm test           # тесты правил
npm run simulate -- 2000 quick   # баланс на партиях ботов
npm run artifact   # одна страница dist/oligarh.html со встроенными моделями
```

## Что есть в прототипе

- Режимы: один против 1–5 ботов; несколько человек на одном телефоне (+ боты), с экраном «Передайте телефон».
- Быстрая партия (15 раундов, по клетке каждому на старте, стройки на 25% быстрее) и классика (до банкротства, максимум 50 раундов).
- Стройки 3 уровней по веткам «Аренда», «Доход», «Особая»; прогресс идёт в чужие ходы; тапы бригады (60 за раунд), сверхурочные, штурм, страховка, бонус «Успел!».
- Аукцион при отказе от покупки, «Слияние» — выкуп последней клетки отрасли за двойную цену.
- Казино: рулетка и слоты, лимит ставки 20%, джекпот.
- Рыночные события каждые 3 раунда, карточки «Новости» и «Госзаказ».

## Пока нет
