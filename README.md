# 📝 Генератор экзаменационных билетов (Flask версия)

> Python + Flask + Groq + Gemini = Никаких проблем с CORS!

## 🎯 Преимущества Flask версии

✅ **Нет проблем с CORS** - все работает через сервер  
✅ **Groq API** - бесплатно и быстро  
✅ **Gemini API** - бесплатно и мощно  
✅ **4 режима работы** - от готовых вопросов до полной автогенерации  
✅ **Экспорт в Word** - скачивание всех билетов  
✅ **Простой деплой** - на Render.com за 5 минут  

## 🚀 Быстрый старт

### Локальный запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/exam-generator-flask

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python app.py
```

Откройте http://localhost:5000

### Деплой на Render.com

1. Создайте аккаунт на [Render.com](https://render.com)
2. Создайте новый **Web Service**
3. Подключите GitHub репозиторий
4. Render автоматически определит настройки
5. Нажмите **Deploy**

Готово! Ваш сайт будет по адресу: `https://exam-generator.onrender.com`

## 🔑 Получение API ключей

### Groq (БЕСПЛАТНО, рекомендуется) ⭐

1. Зайдите на https://console.groq.com/keys
2. Создайте аккаунт (через Google)
3. Нажмите "Create API Key"
4. Скопируйте ключ (начинается с `gsk_...`)

**Преимущества:**
- ✅ Полностью бесплатно
- ✅ Очень быстрый
- ✅ Модель llama-3.3-70b (мощная!)
- ✅ 30 запросов/минуту

### Google Gemini (БЕСПЛАТНО)

1. Зайдите на https://aistudio.google.com/app/apikey
2. Войдите через Google
3. Нажмите "Create API key"
4. Скопируйте ключ (начинается с `AIza...`)

**Преимущества:**
- ✅ Бесплатно (60 запросов/минуту)
- ✅ Модель gemini-2.0-flash
- ✅ Хорошее качество генерации

## 💡 Режимы работы

### 1️⃣ Готовые вопросы
- Загрузите или введите готовые вопросы
- Билеты генерируются случайным образом
- **Не требует API ключ**

### 2️⃣ Темы + ИИ
- Укажите предмет и список тем
- ИИ сгенерирует вопросы по каждой теме
- Требует API ключ

### 3️⃣ Автогенерация
- Укажите только предмет
- ИИ сам придумает темы и вопросы
- Можно указать уровень сложности
- Требует API ключ

### 4️⃣ По блокам
- Структурированные вопросы по модулям
- Из каждого блока берется N вопросов
- **Не требует API ключ**

## 🐛 Troubleshooting

**Ошибка API:**
- Проверьте правильность ключа
- Убедитесь что выбран правильный провайдер
- Для Groq убедитесь что ключ начинается с `gsk_`
- Для Gemini убедитесь что ключ начинается с `AIza`

**Медленная генерация:**
- Это нормально для больших запросов
- Groq быстрее Gemini
- Попробуйте уменьшить количество вопросов

**Не скачивается файл:**
- Проверьте что билеты сгенерированы
- Попробуйте другой браузер
- Очистите кэш браузера
