# АРГО — концепция собственного самообучающегося ИИ

> Версия 0.1 · этап «Концепция»

---

## 1. Что такое Арго в одном абзаце

**Арго** — это твой собственный ИИ-сервис с двумя сторонами:

- **Мастерская (только для тебя)** — здесь ты обучаешь Арго: подключаешь «учителей»
  (любые ИИ: Gemini, Groq/Llama, Claude, GPT, DeepSeek, локальные модели),
  загружаешь знания, проверяешь ответы, одобряешь новые навыки.
- **Портал (для людей)** — обычный сайт с регистрацией, личным кабинетом, историей
  чатов, лимитами и тарифами. Люди просто пользуются тем, что Арго уже умеет.

Арго **растёт по уровням**: текст → документы и презентации → картинки → голос →
видео → агенты. Каждый следующий уровень открывается, когда предыдущий
стабильно работает.

---

## 2. Честно: что значит «сам себя достраивает»

Обучить с нуля модель уровня ChatGPT в одиночку невозможно (нужны миллионы долларов
и тысячи видеокарт). Поэтому Арго устроен по-другому — так же, как устроены
большинство реальных ИИ-продуктов:

| Слой | Что это | Как «учится» |
|------|---------|--------------|
| **Мозг** | Внешние ИИ-модели через API (учителя) | Ты выбираешь, какие модели подключены и для каких задач |
| **Память** | Своя база знаний (документы, ответы, факты) | Пополняется автоматически из разговоров и твоих загрузок |
| **Опыт** | Сохранённые лучшие ответы (оценки 👍/👎) | Арго подмешивает лучшие примеры в новые ответы |
| **Навыки** | Модули: «сделать презентацию», «сделать видео»… | Арго **сам предлагает** новые навыки, ты одобряешь |
| **Своя модель** (позже) | Небольшая открытая модель, дообученная на опыте Арго | Дистилляция: учителя отвечают → Арго учится на их ответах |

**Саморазвитие = цикл:**

```
  ┌──────────────────────────────────────────────────────────┐
  │ 1. Люди задают вопросы / дают задачи                     │
  │ 2. Арго отвечает (сам или через учителей)                │
  │ 3. Ответы оцениваются (люди 👍/👎 + ИИ-экзаменатор)       │
  │ 4. Лучшее → в память и в датасет обучения                │
  │ 5. Если задачу решить не смог → Арго пишет               │
  │    «заявку на новый навык» (план + код/промпт)           │
  │ 6. Ты в Мастерской нажимаешь «Одобрить» или «Отклонить»  │
  │ 7. Навык включается → Арго умеет больше → к шагу 1       │
  └──────────────────────────────────────────────────────────┘
```

> ⚠️ Шаг 6 (твоё одобрение) — обязательный. ИИ, который сам без контроля меняет
> свой код и выпускает это к людям, — это путь к поломкам, утечкам и счетам на
> тысячи долларов за API. Арго предлагает — хозяин решает.

## 3. Уровни развития Арго

| Уровень | Название | Что умеет | Технологии | Условие перехода |
|---|---|---|---|---|
| **1** | Слово | Чат, ответы, тексты, статьи, билеты, память о пользователе | LLM через API, база знаний (RAG) | 500+ оценённых ответов, ≥80% 👍 |
| **2** | Документ | Word, PDF, **презентации PowerPoint**, таблицы Excel | python-docx, python-pptx, openpyxl | Навык «Презентация» проходит экзамен |
| **3** | Образ | Картинки для слайдов, обложки, иллюстрации, понимание фото | Модели генерации изображений через API | — |
| **4** | Голос | Озвучка текста, распознавание речи, голосовой чат | TTS / STT (Whisper и аналоги) | — |
| **5** | Видео | Видео из презентации + озвучка, короткие ролики, субтитры | ffmpeg (слайды+голос), затем видео-модели через API | — |
| **6** | Агенты | Арго создаёт агентов: «исследователь», «копирайтер», «SMM-менеджер» — они сами планируют шаги и пользуются навыками уровней 1–5 | Планировщик задач, инструменты, очередь задач | — |
| **7** | Своя модель | Дообученная открытая модель (Llama/Qwen/Mistral) на опыте Арго — дешевле и независимее | LoRA-дообучение на арендованной видеокарте | Датасет 5 000+ хороших примеров |

Каждый уровень — это **набор навыков**. Навык = файл-описание + код/промпт +
экзамен (набор тестовых заданий). Навык включается для людей только после того, как
сдал экзамен и ты его одобрил.

## 4. Как ты будешь обучать Арго (очень просто)

Всё делается в **Мастерской** — кнопками, без программирования.

### 4.1. Подключить учителей
Вставляешь API-ключ → выбираешь модель → задаёшь роль:
«Gemini — основной учитель», «Groq — быстрые ответы», «Claude — экзаменатор».
Ключи хранятся зашифрованными на сервере, людям не видны.

### 4.2. Урок «Учитель → Арго» (дистилляция)
1. Выбираешь тему (например «Экзамены по истории») или загружаешь список вопросов.
2. Нажимаешь **«Провести урок»** — Арго задаёт вопросы 2–3 учителям.
3. Экзаменатор выбирает лучший ответ, ты можешь поправить.
4. Результат сохраняется в **Память** и в **Датасет**.

### 4.3. Загрузить знания
Перетаскиваешь файлы (PDF, Word, TXT, ссылки на сайты) → Арго разбивает их на
кусочки и запоминает. Теперь он отвечает, опираясь на твои материалы.

### 4.4. Проверять и оценивать
Лента «Последние ответы людям» с кнопками 👍 / 👎 / ✏️ исправить.
Исправленный ответ — самый ценный урок.

### 4.5. Одобрять навыки
Раздел **«Заявки Арго»**: «Меня 12 раз просили сделать презентацию, а я не умею.
Вот план навыка и тестовый результат. Включить?» → **Одобрить / Отклонить**.

### 4.6. Повышать уровень
Панель прогресса показывает, сколько осталось до следующего уровня, и кнопку
**«Открыть уровень»**, когда условия выполнены.

### 4.7. (Позже) Обучить свою модель
Кнопка **«Экспорт датасета»** → файл, который загружается в Google Colab / Kaggle /
RunPod с готовым блокнотом дообучения → получаешь свою модель → подключаешь её как
ещё одного «учителя» (и постепенно делаешь основной).

## 5. Портал для людей

### Регистрация и вход — «как положено»
- Регистрация по e-mail + пароль (пароль хранится только в виде хэша).
- Подтверждение e-mail письмом со ссылкой.
- Восстановление пароля.
- Вход через Google / Яндекс / Telegram (этап 2).
- Галочка согласия с Политикой конфиденциальности и Пользовательским соглашением.
- Защита: ограничение попыток входа, капча при подозрительной активности.

### Роли
| Роль | Кто | Доступ |
|---|---|---|
| **Хозяин** (admin) | Ты | Всё + Мастерская |
| **Модератор** | Помощники (позже) | Проверка ответов, жалобы |
| **Пользователь** | Люди | Портал в рамках тарифа |

### Что видит пользователь
- **Чат с Арго** (как ChatGPT), история диалогов.
- **Инструменты** по открытым уровням: «Сделать презентацию», «Сделать видео»,
  «Мои агенты» — появляются по мере роста Арго.
- **Мои файлы** — всё, что Арго создал для пользователя.
- **Профиль и тариф**: лимиты запросов в день, оплата (этап 3).
- Кнопки 👍/👎 под ответами — люди тоже помогают учить Арго.

### Тарифы (пример)
| Тариф | Цена | Лимиты |
|---|---|---|
| Старт | 0 ₽ | 20 сообщений/день, только текст |
| Плюс | ~299 ₽/мес | 300 сообщений/день, презентации, картинки |
| Про | ~990 ₽/мес | Видео, агенты, приоритет |

Лимиты обязательны: каждый запрос к учителям стоит денег.

## 6. Архитектура

```
                    ┌────────────────────────────┐
   Люди ──HTTPS──▶  │   ПОРТАЛ (сайт)             │
                    │   регистрация, чат, файлы   │
   Ты  ──HTTPS──▶   │   МАСТЕРСКАЯ (/admin)       │
                    └─────────────┬──────────────┘
                                  │
                    ┌─────────────▼──────────────┐
                    │   ЯДРО АРГО (Python API)    │
                    │  ┌──────────────────────┐   │
                    │  │ Маршрутизатор:        │   │
                    │  │ какой навык/учитель?  │   │
                    │  └──────────┬───────────┘   │
                    │   Навыки  Память  Экзамены  │
                    └───┬─────────┬─────────┬────┘
                        │         │         │
       ┌────────────────▼─┐  ┌────▼─────┐ ┌─▼──────────────┐
       │ УЧИТЕЛЯ (API)    │  │ БАЗА     │ │ ФАЙЛЫ          │
       │ Gemini, Groq,    │  │ Postgres │ │ S3-хранилище   │
       │ Claude, GPT,     │  │ +pgvector│ │ (pptx, mp4...) │
       │ DeepSeek, своя   │  │ (память) │ │                │
       └──────────────────┘  └──────────┘ └────────────────┘
                        │
               ┌────────▼────────┐
               │ ОЧЕРЕДЬ ЗАДАЧ   │  ← долгие задачи: видео, агенты, уроки
               │ Redis + воркер  │
               └─────────────────┘
```

### Технологии (выбраны под то, что ты уже знаешь — Python/Flask/Render)
| Часть | Выбор | Почему |
|---|---|---|
| Язык | **Python 3.11+** | Ты уже пишешь на нём; все ИИ-библиотеки на Python |
| Веб-сервер | **FastAPI** (или Flask, как в билетах) | Быстрый, удобен для API и потоковых ответов |
| Интерфейс | HTML + JS (позже React) | Можно начать просто, как в текущем проекте |
| База данных | **PostgreSQL + pgvector** | Пользователи, чаты и «память» в одной базе |
| Очередь | **Redis + RQ/Celery** | Видео и уроки идут минутами — нельзя держать запрос |
| Файлы | **S3-совместимое хранилище** | Презентации и видео не хранят на диске сервера |
| Учителя | Единый адаптер `teachers/` | Новый ИИ подключается одним файлом |
| Упаковка | **Docker Compose** | Один запуск — вся система на любом сервере |

## 7. Где разместить Арго

### Вариант А — Быстрый старт (бесплатно / почти бесплатно)
Подходит для уровней 1–2 и первых пользователей.
- **Render.com** — сайт и ядро (ты уже деплоил туда билеты).
- **Neon.tech** или **Supabase** — бесплатный PostgreSQL с pgvector.
- **Upstash** — бесплатный Redis.
- **Cloudflare R2** — хранилище файлов (10 ГБ бесплатно).
- Минусы: бесплатный Render «засыпает», мало памяти — видео так не сделать.

### Вариант Б — Рабочий (рекомендую с уровня 3)
Один VPS-сервер, всё в Docker:
- **Россия** (если пользователи — граждане РФ): Timeweb Cloud, Selectel, REG.RU —
  ~600–1500 ₽/мес за 2–4 ядра / 4–8 ГБ.
- **Европа**: Hetzner — ~5–10 €/мес.
- Домен (например `argo-ai.ru`) — ~200–900 ₽/год, бесплатный HTTPS через Let's Encrypt.

> ⚖️ **Важно для РФ — закон 152-ФЗ:** если регистрируешь граждан России, их
> персональные данные (e-mail, имя) должны храниться на серверах в России, а на сайте
> должна быть Политика обработки персональных данных. Поэтому для «боевого» запуска
> в РФ база пользователей — на российском VPS.
> Также учти: часть зарубежных ИИ-API недоступна из РФ напрямую — ядро Арго с
> учителями можно держать на зарубежном сервере, а базу пользователей — на российском.

### Вариант В — Обучение своей модели (уровень 7)
Видеокарта арендуется **только на время обучения** (часы, не месяцы):
Google Colab / Kaggle (бесплатно, для малых моделей), RunPod / Vast.ai
(~0,3–1 $/час за мощную карту).

## 8. Как разместить (кратко; подробная инструкция — на этапе 1)

1. Создаёшь сервер (Вариант А или Б).
2. Копируешь проект с GitHub: `git clone ...`
3. Заполняешь файл `.env` (ключи учителей, пароль базы, почта для писем).
4. Запускаешь одной командой: `docker compose up -d`
5. Открываешь сайт → регистрируешься → первый зарегистрированный с e-mail из
   `.env` автоматически становится **Хозяином** и получает доступ к Мастерской.
6. Подключаешь учителей и проводишь первый урок.

Обновление Арго: `git pull && docker compose up -d --build`.

## 9. Безопасность и контроль

- API-ключи учителей — только на сервере, в зашифрованном виде.
- Лимиты на пользователя и **общий дневной бюджет** на учителей (Арго
  остановится, а не разорит тебя).
- Модерация: фильтр запрещённого контента на входе и выходе.
- Навыки с кодом выполняются в изолированной «песочнице» (отдельный контейнер
  без доступа к базе пользователей).
- Резервные копии базы — ежедневно.
- Журнал всех действий Мастерской.
